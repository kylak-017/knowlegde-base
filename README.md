# Nanoforge: DFT & DMFT Workspace

Welcome to the **Nanoforge** repository. This project serves a dual purpose: hosting core scientific computation scripts alongside a readable, interactive knowledge base detailing the underlying theory.

## 🌿 Branch Navigation

To help you find what you need, this repository is organized into two primary tracks across different branches:

*   **`main` Branch (Code Workspace)**: This is the default branch. It contains the primary functional code, scripts, and implementation environments for **Density Functional Theory (DFT)** and **Dynamical Mean-Field Theory (DMFT)** workflows.
*   **`v5` Branch (Theory & Notes Website)**: This branch contains the source code for a launchable, human-readable documentation website. It acts as a dedicated knowledge base storing comprehensive notes, derivations, and guides related to the core theories of DFT and DMFT.

---

## 🚀 Getting Started

### 1. Working with the DFT/DMFT Code
To explore or execute the calculation scripts, ensure you are on the `main` branch:
```bash
git checkout main
```

### 2. Viewing the Knowledge Base Website
To view or locally serve the notes and documentation website, switch to the `v5` branch:
```bash
git checkout v5
```
